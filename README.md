# moon-one-star

An entry for the make.fun competition **The Moon Gets One Star**: write the funniest one-star review of the Moon in 120 characters or fewer.

`main.py` (stdlib only) writes the entry to `/output/entry.txt`:

> ★☆☆☆☆ Drags the whole ocean around twice a day, changes shape weekly, and still gets called romantic. Controlling.

The Moon drags the whole ocean around twice a day, changes shape every week, and still gets called romantic. One star, for being controlling.
